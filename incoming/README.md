# 素材の受け取り用フォルダ

画像はここにアップロードしてください。アプリへの組み込み（縮小・切り抜き・変換）はこちらで行います。

| フォルダ | 入れるもの |
|---|---|
| `backgrounds/` | 背景（`docs/ASSET_BRIEF_2.md` のセクション1） |
| `parts/` | 木の看板などの部品（セクション2） |
| `icons/` | アイコン（セクション3） |
| `route/` | 登山ルート図（セクション4） |
| `photos/` | 実写の写真（コース選択の背景・アルバム用）。山ごとにファイル名に山名を入れてください |
| `characters/` | キャラクターの追加・差し替え |

## アップロードのしかた（GitHub のサイトから）
1. このフォルダの中の、入れたいフォルダ（例：`icons`）を開く
2. 右上の「Add file」→「Upload files」
3. 画像をまとめてドラッグして入れる（1回に100枚まで、1枚25MBまで）
4. 下の「Commit changes」を押す

ファイル名は `docs/ASSET_BRIEF_2.md` の表のとおりにしてください（日本語の名前でも組み込めますが、表どおりだと早く済みます）。
