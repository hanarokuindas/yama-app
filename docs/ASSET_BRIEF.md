# 画像アセット制作指示書（山アプリ）

この文書だけで作業が完結するように書いています。必要な画像は全部で **111枚** です。

| セクション | 内容 | 枚数 |
|---|---|---|
| 1 | 山の固有種スプライト（八ヶ岳32枚は受領済み） | 86 |
| 2 | UIアイコン | 9 |
| 3 | 山神キャラクター | 14 |
| 4 | 差し替え | 2 |

---

## 0. 共通仕様

| 項目 | 指定 |
|---|---|
| ファイル名 | 表のIDをそのまま使う（連番・ハッシュを付けない、大文字小文字も一致させる） |
| 形式 | PNG |
| サイズ | セクション1・3は1024×1024px、セクション2は512×512px |
| 構図 | 被写体は中央、周囲に1割の余白 |
| 文字 | 画像内に文字・ロゴ・枠を入れない |

背景の抜きや色調整はこちらで行います。

フォルダ構成：

```
specimens/                ← セクション1（86枚）
icons/                    ← セクション2（9枚）
characters/yatsugatake/   ← セクション3
characters/hakone/        ← セクション3
```

## 1. 山の固有種スプライト（86枚・最優先）

山探索ミニゲームで使う標本の絵です。**1種＝1つの見た目**である必要があります
（同じ絵が複数あるとマッチングゲームが成立しません）。

スタイルは既に納品済みの共通102種と揃えてください。3Dレンダー風のミニチュア標本です。

> **注意：生物とは限りません。** 山の固有コンテンツには土偶・石像・温泉・伝承の妖怪なども含まれます。
> 各行の「種別」列を必ず確認してください。
