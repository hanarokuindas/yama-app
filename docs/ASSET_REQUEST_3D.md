# 山探索（トリプルマッチ）用アセット依頼

## 受領状況（2026-07-27）

- **共通102種のスプライト：全て受領・組み込み済み**（A1〜A26 / B1〜B41 / C1〜C35）
- **演出用3枚：受領・組み込み済み**（tray_slot / fx_sparkle / fx_dust）
- 山の固有種118種：**未着**（現在はアイコン流用で表示中）

生成物には背景（市松模様・黒・クリーム）が焼き込まれていたため、
外周から背景色を学習して除去し、透過WebP化しています（53.8MB → 約1.7MB）。


## 結論：3Dモデルより「3D風スプライト」を推奨します

Match 3D 系のゲームは3Dモデルで作られていますが、このアプリは**Webデモ**であり、
現状の構成（React + 画像アセット）に対して 3D を入れると次のコストが乗ります。

| | 3Dモデル（glTF + three.js） | 3D風スプライト（推奨） |
|---|---|---|
| 必要アセット | 220体のモデル＋テクスチャ＋ライティング調整 | 220枚の画像（既存パイプラインのまま） |
| 追加ライブラリ | three.js 約600KB | 不要 |
| スマホでの負荷 | 100個以上の同時描画で発熱・電池消費 | ほぼ無し |
| 制作コスト | 1体あたり数時間〜 | 1枚あたり生成AIで数十秒 |
| 見た目の差 | 回転できる／光沢が動く | **静止画では区別がつかない** |

Match 3D の「立体感」の正体は、**斜め見下ろしの角度・落ち影・重なり**です。
これらは画像でも再現でき、実際に現在の実装では傾き・重なり・奥行きによる明暗を
CSSで付けています。ここに**斜め45°から見下ろした3DCG風の画像**を入れれば、
見た目はMatch 3Dとほぼ同等になります。

**3Dモデルが本当に必要になるのは**、掴んで回して観察する・物理で崩れる山を作る、
といった「立体である必然性」がある演出を入れる場合です。
そこまでやるなら別途ご相談ください（その場合の仕様も本書末尾に記載）。

## 依頼したいもの（優先度順）

### ① 標本スプライト 102種（最優先）

現在は既存アイコンを使い回しているため、**別の種が同じ絵**になっています。
マッチングゲームとして成立させるには、**1種＝1つの見た目**が必須です。

- 置き場所：`src/assets/specimens/<ID>.png`
- サイズ：**512×512px 透過PNG**
- 構図：**斜め上45°から見下ろした角度**／被写体は中央／余白1割
- ライティング：左上からの光。**接地影を必ず付ける**（楕円のソフトシャドウ）
- 質感：`3D render, soft studio lighting, subtle rim light, glossy or matte per material`
- 縁取り：白フチは**不要**（3D風にするため）

## 生成プロンプト（コピペ用）

```
3D rendered game asset of <対象名>, isometric 45-degree top-down view,
soft studio lighting from upper left, subtle rim light, soft contact shadow beneath,
clean readable silhouette, vibrant but natural colors, mobile match-3D game style,
centered composition, transparent background, 512x512, no text, no watermark
```

材質ごとの追記例：
- 鉱物 → `crystalline, glossy facets, subsurface scattering`
- 動物 → `cute stylized figurine, smooth matte finish`
- 植物・キノコ → `botanical specimen, soft matte leaves, slight translucency`

## 組み込み方法

`src/assets/specimens/` に **図鑑IDのファイル名** で置いてください。
コード側で `encyclopedia.json` の `id` と自動で突き合わせます
（現在はアイコン流用中。スプライトが1枚でも入ればその種だけ差し替わります）。

```
src/assets/specimens/A1.png    ← フェルドスパー
src/assets/specimens/B7.png    ← ホンドオコジョ
src/assets/specimens/YAT1.png  ← 八ヶ岳の黒曜石
```

## 付録：本当に3Dで作る場合の仕様

| 項目 | 要件 |
|---|---|
| 形式 | glTF 2.0（.glb、Draco圧縮） |
| ポリゴン数 | 1体 1,500〜3,000 tris |
| テクスチャ | 512×512 baseColor＋ORM（1体あたり最大2枚） |
| 原点 | 底面中心（接地させるため） |
| スケール | 1辺 1.0 に正規化 |
| マテリアル | PBR metallic-roughness。アニメーション不要 |
| 1体あたり容量 | 200KB以下 |

導入する場合は three.js（+ @react-three/fiber）を追加し、
インスタンシングで100個以上を1ドローコールにまとめる実装に切り替えます。
その際は**低スペック端末向けにスプライト版へ自動フォールバック**する二重構成が必要です。
